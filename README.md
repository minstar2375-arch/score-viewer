# 악보함

PDF 악보를 모아 두고, 보고, 필기하는 웹앱입니다.

## 갤럭시 탭에 설치

1. 탭의 Chrome에서 https://minstar2375-arch.github.io/score-viewer/ 를 엽니다.
2. 오른쪽 위 메뉴(⋮)에서 `앱 설치` 또는 `홈 화면에 추가`를 누릅니다.
3. 홈 화면의 악보함 아이콘으로 실행합니다. 한 번 연 뒤에는 인터넷 없이도 열립니다.

악보 PDF는 올라가지 않고 탭 안에만 저장됩니다.

## Mac에서 실행

`시작하기.command`를 더블클릭하면 브라우저에서 열립니다. 끝낼 때는 터미널 창을 닫으세요.
`index.html`을 직접 열면 동작하지 않으며, 웹 서버를 통해 열어야 합니다.

## 쓰는 법

| 동작 | 방법 |
| --- | --- |
| 악보 추가 | `추가` 버튼 또는 PDF를 화면에 끌어다 놓기. 내용이 같은 파일은 이름이 달라도 확인 창으로 알려 주고 추가하지 않습니다. 이름만 같고 내용이 다른 파일은 추가할지 물어봅니다 |
| 쪽 넘기기 | 화면 왼쪽/오른쪽 누르기, 밀기, 방향키, PageUp/PageDown, 스페이스 (키보드 입력을 보내는 블루투스 페달 포함) |
| 악보만 크게 보기 | 보기 모드에서 화면 가운데 누르기 |
| 필기 | 펜, 형광펜, 글자, 지우개. 쓰는 즉시 저장됩니다 |
| 피아노 건반 | `건반` 버튼으로 열고 닫기. 화음과 미끄러지듯 연주하기 가능, 화살표로 옥타브 이동(C1~C8), 음 이름 표시 전환. 파란 점이 있는 건반이 가온 도(C4)입니다 |
| 연습 음원 | 헤드폰 버튼에서 MP3 등 음원 파일이나 YouTube Music 곡 링크를 악보에 연결. 재생 막대에서 일시정지, 5초 앞뒤로 이동, A-B 구간 반복, 느린 속도(음 높이 유지). 목록의 재생 버튼으로도 일시정지할 수 있습니다. 음원 파일은 앞부분 무음을 자동으로 건너뜁니다(원본은 그대로이며, 곡에서 가장 큰 소리보다 40dB 넘게 작은 구간만 무음으로 봅니다). 파일은 인터넷 없이 재생되고, YouTube 곡은 인터넷이 필요합니다. 다른 앱에서 재생을 막은 곡은 YouTube Music으로 열어 분할 화면으로 함께 볼 수 있습니다 |
| 연습 녹음 | 마이크 버튼으로 녹음 창 열기. 녹음은 악보별로 저장되고, 다시 듣기, 위치 이동, 파일로 저장, 삭제가 됩니다. 다른 앱으로 넘어가면 녹음을 멈추고 저장합니다. 재생 중인 음원 파일은 녹음에 직접 섞입니다(YouTube 곡은 제외). 녹음은 MP3로 저장되며 공유 버튼으로 카카오톡 등 다른 앱에 보낼 수 있습니다 |
| 정렬 | 보관함에서 `최근 본 순`, `가나다순` 선택. 고른 방식을 기억합니다 |
| 백업, 복원 | 보관함 오른쪽 위 `⋯`에서 악보, 필기, 녹음, 연습 음원을 파일 하나로 저장하고 되살립니다. 이미 있는 악보는 건너뜁니다 |
| 다크 모드 | 기기 설정을 따릅니다. 보관함 위쪽의 달/해 버튼으로 직접 고르면 그 설정을 기억합니다 |
| 이름 변경, 삭제 | 보관함에서 악보 표지의 `⋯` 버튼 |
| 이 쪽 필기 모두 지우기 | 지우개를 고르면 나타나는 버튼 |

필기 모드에서는 손이 닿아 쪽이 넘어가지 않도록 화면 누르기로 쪽을 넘기지 않습니다. 아래쪽 화살표나 키보드를 쓰세요.

S펜을 한 번 쓰면 그 뒤로는 펜으로만 필기됩니다. 손바닥이 닿아도 그려지지 않게 하기 위해서입니다.

악보를 보는 동안에는 화면이 꺼지지 않습니다. 배터리 절약 모드에서는 이 기능이 동작하지 않을 수 있습니다.

## 저장 위치

악보와 필기는 쓰고 있는 브라우저 안(IndexedDB)에만 저장됩니다. 서버로 전송되지 않습니다.

- 브라우저 사이트 데이터를 지우면 악보와 필기도 함께 지워집니다. 백업 파일을 저장해 두면 되살릴 수 있습니다.
- 기기나 브라우저 사이에 자동으로 동기화되지 않습니다.
- 주소가 바뀌면(포트 포함) 다른 저장소로 취급됩니다.

## 구성

- `js/viewer.js`: 악보 표시, 필기, 쪽 넘기기
- `js/app.js`: 보관함, 화면 전환
- `js/db.js`: 저장소
- `sw.js`: 오프라인 지원. 파일을 고치면 `VERSION`을 올리세요
- `vendor/pdfjs/`: [PDF.js](https://mozilla.github.io/pdf.js/) 4.10.38 호환성 빌드 (Apache-2.0)
- `vendor/lamejs/`: 녹음을 MP3로 바꾸는 [lamejs](https://github.com/zhuker/lamejs) 1.2.1 (LGPL-3.0)
- `audio/piano/`: 피아노 녹음. [Salamander Grand Piano](https://github.com/sfzinstruments/SalamanderGrandPiano), Alexander Holm 제작, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). [Tone.js](https://tonejs.github.io/audio/salamander/)가 MP3로 변환해 공개한 파일을 그대로 씁니다.
